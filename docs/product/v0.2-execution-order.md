## Delivery Profiles

Assisted-pilot readiness and fundraising-demo readiness are different delivery profiles. Neither is a separate product version, and neither by itself establishes a version.

### Assisted Pilot

```yaml

  Test whether a real target-adjacent user can understand and complete the
  governed review workflow.
external_SRT_import: allowed
built_in_ASR_required: false
operator_assistance: allowed
primary_version_relationship: v0.2_external_testability
```

An assisted pilot may use an externally produced SRT. This allowance supports a bounded validation session and does not declare external SRT to be the permanent preferred onboarding flow.

### Fundraising Demonstration

```yaml
purpose: >
  Demonstrate a coherent product experience and commercial thesis without
  requiring the observer to mentally assemble several unrelated tools.
media_import: required
built_in_ASR: required
external_SRT_import: retained
governed_review: required
human_confirmed_manual_correction: required
bounded_correction_reuse_demonstration: required
self_service_or_production_readiness: not_implied
```

Built-in ASR is an onboarding capability and a producer of an immutable, non-authoritative `TranscriptObservation`. ASR output never becomes canonical transcript authority. Only explicit human decisions can authorize canonical reviewed output.

The ASR runtime, model, backend, and distribution mechanism remain unresolved. External SRT import remains supported alongside the fundraising-demo media-to-review path.
